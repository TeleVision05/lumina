# e2e fixtures

All footage here is synthetic and generated by this repo (no third-party media).

| File                                                     | What                                                                                                                                                                                                      | How it is made                                                    |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `scene.ts`                                               | The synthetic room: warm grey wall, darker table, a bright warm lamp at the upper **left** of the sensor image for the first 2 s and the upper **right** for the last 2 s (320 x 240, 15 fps, 4 s, loops) | Code                                                              |
| `../../test-results/fixtures/room.y4m`                   | Fake camera feed for Chromium (`--use-file-for-fake-video-capture`)                                                                                                                                       | Written by `e2e/global-setup.ts` before every run (not committed) |
| `../../test-results/fixtures/room-lamp-{left,right}.png` | First and last frame, for the dropped-image tests                                                                                                                                                         | Written by `e2e/global-setup.ts`                                  |
| `placeholder-clip.mp4`                                   | The same 4 s clip as VP9 in MP4 (2,809 bytes), for the dropped-video test                                                                                                                                 | Committed. Regenerate with the commands below                     |

VP9, not H.264: Playwright's Chromium is an open-source build without the H.264 decoder. Real sample
clips in `public/samples/` should be H.264 MP4 for Safari; Chrome and Firefox play both.

Regenerate the clip (ffmpeg 8.1 was used on 2026-11-13):

```sh
cd web
node --experimental-transform-types --no-warnings \
  -e "import('./e2e/fixtures/scene.ts').then(m => m.writeY4m('/tmp/room.y4m'))"
ffmpeg -y -threads 4 -i /tmp/room.y4m -c:v libvpx-vp9 -b:v 0 -crf 45 -pix_fmt yuv420p -an \
  -row-mt 1 e2e/fixtures/placeholder-clip.mp4
```
